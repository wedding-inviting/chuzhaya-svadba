# Чужая свадьба 💗

> Когда хочется праздника, но никто не женится.

Одностраничный сайт-приглашение на тематическую вечеринку **«Чужая свадьба»** — свадьбу, на которой нет настоящих молодожёнов, зато есть роли, драма и веселье.

🔗 **Демо:** https://wedding-inviting.github.io/chuzhaya-svadba/

---

## 📖 О проекте

Это лендинг-приглашение на мероприятие, которое организует свадебное агентство **Ruzmaykina_wedding**. Гостям предлагается прийти на «чужую свадьбу» в одном из образов — сварливой свекрови, троюродной тёти, бывшего одноклассника или таинственного гостя.

Сайт выполняет три задачи:
- **Презентует концепцию** вечеринки и заражает настроением;
- **Знакомит с ролями** и программой торжества;
- **Собирает заявки** на участие с выбором роли и последующей оплатой.

## 🚀 Локальный запуск

```bash
# Клонировать репозиторий
git clone https://github.com/wedding-inviting/chuzhaya-svadba.git
cd chuzhaya-svadba

# Открыть в браузере
open index.html   # macOS
start index.html  # Windows
xdg-open index.html  # Linux
```

Либо запустить локальный сервер:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 📬 Как оставить заявку

1. Прокрутить до секции **«Ну что, ты с нами?»**
2. Ввести имя и выбрать роль
3. Отправить форму — заявка уйдёт организаторам на почту
4. Перевести **3 500 ₽** по указанному номеру телефона, указав ФИО
5. Готово — можно закрывать страницу 🎉
